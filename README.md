# Flow — тренажёр речи

Мобильная PWA-версия тренажёра. Работает без сервера и без сборки: обычные HTML/CSS/JS-файлы.

## Как запустить через GitHub Pages

1. Создай на GitHub новый репозиторий, например `flow-speech-trainer`.
2. Загрузи **все файлы из этой папки** в корень репозитория.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Branch: `main`, Folder: `/ (root)`, затем **Save**.
6. GitHub покажет адрес вида `https://USERNAME.github.io/flow-speech-trainer/`.
7. Открой этот адрес на телефоне.

## Установка на телефон

### Android / Chrome
Открой сайт и нажми кнопку со стрелкой в правом верхнем углу либо меню браузера → **Установить приложение** / **Добавить на главный экран**.

### iPhone / Safari
Открой сайт → кнопка **Поделиться** → **На экран «Домой»**.

После первого открытия через GitHub Pages основные файлы кэшируются, поэтому приложение может работать офлайн.

## Что есть внутри

- 5 упражнений в фиксированном порядке;
- 150 быстрых вопросов;
- 62 темы «Запретное слово»;
- 53 начала истории;
- 98 неожиданных поворотов;
- 73 абсурдные позиции;
- 75 бытовых сюжетов;
- таймеры и звуковые сигналы;
- пауза, пропуск, «Другая тема»;
- три пресета длительности и ручные настройки;
- сохранение настроек и статистики на устройстве;
- серия дней и минуты практики;
- PWA/офлайн-режим;
- попытка не гасить экран во время тренировки, если браузер поддерживает Screen Wake Lock.

## Локальный запуск на компьютере

Для проверки PWA лучше запускать через локальный HTTP-сервер, а не двойным кликом по `index.html`:

```bash
python -m http.server 8000
```

После этого открой `http://localhost:8000`.
